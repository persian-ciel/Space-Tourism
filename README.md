# Space Tourism

A simple **Space Tourism site** built with **React** and **Vite**.

---

## Features

- page navigation
- Reusable components
- designed with **Tailwind CSS**

---

## Tech Stack

- React
- Vite
- Tailwind CSS

---

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or newer)
- npm or Yarn (depending on your preference)

### Installation

```bash
git clone https://github.com/persian-ciel/Multi-Step-Site.git
cd Multi-Step-Site
npm install
npm install react-router-dom
npm istall react-swipeable
```

### Running Locally

```bash
npm run dev
```

This launches the development server with HMR at http://localhost:5173 (default). Any changes you make update instantly.
